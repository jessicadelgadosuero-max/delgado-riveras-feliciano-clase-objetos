# delgado-riveras-feliciano-clase-objetos


# ¿Qué hace el programa?

# Permite registrar productos de una tienda en una aplicación de consola, gestionando sus datos esenciales, validando información incorrecta y calculando automáticamente el valor total en existencia de cada producto.

# Datos de entrada: Código del producto, nombre, precio unitario y cantidad en existencia ingresados por el usuario mediante la consola.

  # Datos que procesa: Validación de reglas de negocio (nombre no vacío, precio > 0, cantidad > 0 y cálculo automático del valor total (⁠Precio × Cantidad⁠).
  


 # Datos de salida: Información detallada de los productos registrados, mensajes de error controlados ante datos inválidos y el valor total calculado.
